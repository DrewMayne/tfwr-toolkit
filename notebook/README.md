# The worksheet

[FromBeginnerToBoard.ipynb](FromBeginnerToBoard.ipynb) is the talk "From Beginner to Board" as a worksheet: the
talk's questions, with space for your own farms and your own working. GitHub shows it as a page; you can also
open it in Jupyter to type your predictions and results into it.

Nothing in it runs by itself. The code cells say which code window to make in the game, what to call it and the
settings to use; you write the farm in the game and run it from your main program with `simulate()`.
`timed` and `bench` come from [kit/toolkit.py](../kit/toolkit.py); `compare` and `simulate_many` need the
[Faster Simulations](../faster-simulations/README.md) mod.
